# Dotfiles - Arch Linux

This repository contains my personal configurations (dotfiles) for **Arch Linux**, focusing on:
- Minimalism
- Modularity
- Reproducibility
- Automation via shell

The settings shown here are used in a Wayland environment and prioritize lightweight and highly customizable tools.

---

## ⚙️ Environment
- OS: Arch Linux
- WM: Hyprland
- Compositor: Wayland
- Shell: Bash
- Terminal: Kitty
- Menu: Rofi
- Status Bar: Waybar
---

## 📁 Repository Structure

```text
dotfiles/
|- bash/                    # Bash shell settings
|- hypr/                    # Hyprland configuration filles
|- rofi /                   # Applets and scripts to quick menus
|- waybar /                 # Status bar for Wayland
|- kitty/                   # Kitty Terminal settings
|- install.sh               # Installation script (to future)
```
